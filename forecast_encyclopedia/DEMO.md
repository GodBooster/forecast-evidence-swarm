# Forecast Evidence Swarm — demonstration script

This is a draft for presenting the working offline prototype. The repository is
private. This document does not claim that a hackathon entry has been submitted or
that NEAR payments have been verified. Check the core team's latest validation
results before adding a contract segment to the presentation.

## Run the actual combined demonstration

From the repository root:

```sh
python3 -m forecast_encyclopedia --core-demo \
  --core-consent fixtures_encyclopedia/core_demo_consent.json \
  --out artifacts/product-demo
python3 -m unittest discover -s tests_encyclopedia -v
```

Open `artifacts/product-demo/index.html` in a permitted local browser. The exported
pages use only local assets. Visual review by this module's authoring session was
blocked by its browser file-URL policy; programmatic link and HTML checks passed.

| Time | Show | Explain |
| --- | --- | --- |
| 0:00–0:25 | Index and synthetic notice | Customers need to inspect what a forecast used, what its critics questioned, and what changed afterward. This demonstration uses scripted roles and fictional data. |
| 0:25–1:00 | Event A: unresolved future event | The exact question, scope, cutoff and resolution rule are visible. A probability is a forecast, not a market quote or established fact. |

## Draft product description

Forecast Evidence Swarm turns a commissioned forecast into an inspectable research
record. A customer defines a question and resolution terms. Analyst, critic and
verifier roles produce a forecast, limitations and evidence checks. The resulting
knowledge page separates delivery validity, customer acceptance and later forecast
accuracy, retaining earlier versions even when the prediction is wrong.

The implemented offline prototype uses deterministic scripted roles and synthetic
fixtures. Its encyclopedia supports explicit publication permission, revocation,
source excerpts, immutable forecast commitments and read-only integration with the
core report. NEAR job escrow is implemented in the core (`contracts/forecast_jobs/`) and
was exercised on a local, ephemeral NEAR Sandbox; its receipts reach pages only through
the separate payment-provenance sidecar (`docs/KNOWLEDGE_DEMO.md`). Live inference,
authenticated external evidence and a betting market are not implemented by this module.
